# Archivum Production Logo Pack

## Core assets
- `wordmark/archivum-wordmark-dark.svg` — primary wordmark for light backgrounds
- `wordmark/archivum-wordmark-light.svg` — primary wordmark for dark backgrounds
- `wordmark/archivum-wordmark-signal.svg` — rare signal-blue layered-crossbar variant
- `compact-a/archivum-a-dark.svg` / `light.svg` — compact mark
- `compact-a/archivum-app-icon.svg` — universal square icon
- `domain-lockup/archivum-domain-lockup.svg` — Archivum + archivum.tech
- `legal-lockup/archivum-legal-lockup.svg` — Archivum LLC
- `favicon/` — favicon SVG/ICO + common PNG sizes
- `social/` — avatar and platform banner exports
- `motion-reference/archivum-a-motion.svg` — lightweight looping digital motion mark

## Colors
- Graphite `#0C0D0F`
- Mineral `#F3F3F0`
- Silver `#A8ADB4`
- Signal Blue `#4DA3FF`

## Integration guidance
- Website nav, decks, press, documents: use the SVG wordmark.
- Dark UI: use `archivum-wordmark-light.svg`.
- Favicon / app icon / social profile: use the compact A, never the full wordmark.
- Legal paperwork: use the legal lockup only when the legal entity name is required.
- Marketing that must surface the URL: use the domain lockup.
- The signal variant is secondary; default brand usage stays monochrome.
- SVG is the master format. PNG exports are convenience assets for platforms that do not accept SVG.

## Note
The lettering is delivered as vector outlines rather than live font text, so the master wordmark does not depend on the recipient having the design font installed.
