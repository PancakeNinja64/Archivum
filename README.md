# Archivum

The system of record for AI data.

Version datasets. Trace lineage. Verify provenance.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion (subtle motion only)
- next-themes (light / dark)

## Develop

```bash
cd site
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
cd site
npm run build
```

The static export is written to `site/out/` when you run `npm run build`. See `DEPLOY-README.md` for deployment options.
