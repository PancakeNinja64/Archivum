# Archivum

The system of record for AI data.

Version datasets. Trace lineage. Verify provenance.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion (subtle motion only)
- next-themes (light / dark)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
